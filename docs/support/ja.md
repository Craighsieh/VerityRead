## 開発を支援する

VerityReadは無料で利用でき、支援によって追加機能が解放されることはありません。
VerityReadが役立った場合は、[PayPalから今後の開発を任意で支援](https://paypal.me/craighsieh)
できます。

<a href="https://paypal.me/craighsieh"><img src="../../assets/support/paypal-qr.svg" alt="VerityReadの開発を支援するPayPal QRコード" width="220" height="220"></a>

決済はPayPalが処理し、PayPalの規約と手数料が適用されます。これは独立した
ソフトウェア開発への任意の支援であり、税控除の対象となる慈善寄付ではありません。

## お問い合わせ前の確認

1. VerityRead → **設定**を開き、**再確認**を選択します。
2. Ollamaを使用する場合は、Ollamaが起動し、選択したモデルがインストール済みで
   あることを確認します。
3. **Ollama接続をテスト**を選択します。CORSエラーが表示された場合は、
   [Ollamaセットアップガイド](../../setup/ja/)の手順で正しい拡張機能オリジンを
   設定してください。
4. 通常の記事ページで再試行してください。Chromeの内部ページや一部の保護された
   ページは拡張機能から読み取れません。

## お問い合わせに含める情報

VerityReadのバージョン、Chromeのバージョン、OS、選択したProviderとモデル、
正確なエラーメッセージをお知らせください。ページ内容、非公開の選択テキスト、
APIキー、パスワード、その他の秘密情報は送信しないでください。
