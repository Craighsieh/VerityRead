## お問い合わせ前の確認

1. VerityRead → **設定**を開き、**再確認**を選択します。
2. Ollamaを使用する場合は、Ollamaが起動し、選択したモデルがインストール済みで
   あることを確認します。
3. **Ollama接続をテスト**を選択します。CORSエラーが表示された場合は、
   [Ollamaセットアップガイド](../../setup/ja/)の手順で正しい拡張機能オリジンを
   設定してください。
4. 通常の記事ページで再試行してください。Chromeの内部ページや一部の保護された
   ページは拡張機能から読み取れません。

## お問い合わせに含める情報

VerityReadのバージョン、Chromeのバージョン、OS、選択したProviderとモデル、
正確なエラーメッセージをお知らせください。ページ内容、非公開の選択テキスト、
APIキー、パスワード、その他の秘密情報は送信しないでください。
