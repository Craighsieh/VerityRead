## 联系前请先检查

1. 打开真阅 → **设置**，点击**重新检查**。
2. 如果使用 Ollama，请确认 Ollama 已启动，并且所选模型已经安装。
3. 点击**测试 Ollama 连接**。如果显示 CORS 错误，请按照
   [Ollama 安装指南](../../setup/zh-CN/)设置正确的扩展程序来源。
4. 请在普通文章页面重试；Chrome 内部页面和部分受保护页面不允许扩展程序读取。

## 联系时请提供

请附上真阅版本、Chrome 版本、操作系统、所选 Provider 和模型，以及完整错误信息。
请勿发送页面内容、私密的选中文本、API Key、密码或其他机密信息。
