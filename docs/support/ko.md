## 문의 전 확인 사항

1. VerityRead → **설정**을 열고 **다시 확인**을 선택하세요.
2. Ollama를 사용하는 경우 Ollama가 실행 중이고 선택한 모델이 설치되어 있는지
   확인하세요.
3. **Ollama 연결 테스트**를 선택하세요. CORS 오류가 표시되면
   [Ollama 설정 가이드](../../setup/ko/)에 따라 정확한 확장 프로그램 출처를
   설정하세요.
4. 일반 기사 페이지에서 다시 시도하세요. Chrome 내부 페이지와 일부 보호된 페이지는
   확장 프로그램에서 읽을 수 없습니다.

## 문의 시 포함할 정보

VerityRead 버전, Chrome 버전, 운영 체제, 선택한 Provider와 모델, 정확한 오류 메시지를
포함해 주세요. 페이지 내용, 비공개로 선택한 텍스트, API 키, 비밀번호 또는 기타
비밀 정보는 보내지 마세요.
