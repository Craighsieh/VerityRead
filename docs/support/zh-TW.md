[English](../) · [繁體中文](./) · [简体中文](../zh-CN/) ·
[日本語](../ja/) · [한국어](../ko/)

電子郵件：[craighsieh@gmail.com](mailto:craighsieh@gmail.com)

## 聯絡前請先檢查

1. 開啟真閱 → **設定**，按下**重新檢查**。
2. 若使用 Ollama，請確認 Ollama 已啟動，且所選模型已安裝。
3. 按下**測試 Ollama 連線**。若顯示 CORS 錯誤，請依
   [Ollama 安裝指南](../../setup/zh-TW/)設定正確的擴充功能來源。
4. 請在一般文章頁重試；Chrome 內部頁面與部分受保護頁面不允許擴充功能讀取。

## 聯絡時請提供

請附上真閱版本、Chrome 版本、作業系統、所選 Provider 與模型，以及完整錯誤訊息。
請勿傳送頁面內容、私密選取文字、API Key、密碼或其他機密資訊。
