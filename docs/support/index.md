## Before contacting support

1. Open VerityRead → **Settings** and choose **Re-check**.
2. If you use Ollama, confirm that it is running and that the selected model is
   installed.
3. Choose **Test Ollama connection**. If a CORS error appears, follow the
   exact-origin steps in the [Ollama setup guide](../setup/).
4. Retry on a normal article page. Chrome internal pages and some protected
   pages cannot be read by extensions.

## What to include

Include the VerityRead version, Chrome version, operating system, selected
Provider and model, and the exact error message. Do not send page content,
selected private text, API keys, passwords, or other secrets.
