# 真閱隱私政策

生效日期：2026 年 7 月 26 日
發布者：VerityRead
聯絡信箱：[craighsieh@gmail.com](mailto:craighsieh@gmail.com)

[English](./) · [简体中文](../zh-CN/) · [日本語](../ja/) · [한국어](../ko/)

## 摘要

真閱是 Chrome 擴充功能，可摘要目前頁面、依據頁面原文回答問題，以及翻譯選取
文字。內容只會透過 Chrome Built-in AI 在裝置上處理，或送到使用者自己的本地
Ollama 服務 `http://127.0.0.1:11434`。

真閱不會將頁面內容、選取文字、提示詞、AI 回答、頁面標題或網址傳送給發布者、
雲端推理服務、分析服務、廣告商或資料仲介。

## 存取與用途

只有在使用者主動選擇功能後，真閱才會暫時存取目前頁面的可讀文字、標題、網址與
網域、使用者選取的文字、輸入的問題，以及本地產生的摘要、翻譯、回答與來源引用。
這些資料只用於提供使用者要求的閱讀功能。真閱不會持續掃描頁面，也不會在背景收集
瀏覽紀錄。

## 本地處理與網路

- Chrome Built-in AI、Translator 與 Language Detector 會在 Chrome 裝置端處理。
- Ollama 內容只送到同一台裝置的 `127.0.0.1:11434`。
- 0.1.0 版沒有雲端推理 fallback。
- Chrome 可能下載模型或語言套件，Chrome Web Store 可能更新擴充功能；真閱不會把
  頁面內容加入這些瀏覽器管理的請求。

## 儲存與保留

預設不保存頁面內容、選取文字、提示詞、AI 回答或任務歷史。真閱會在本地保存
Provider、模型、翻譯目標、隱私同意版本及網站權限等偏好。

摘要快取預設關閉。使用者明確開啟後，摘要及其頁面網址可能保存在本地 IndexedDB，
直到使用者清除快取、清除所有本機資料或解除安裝。0.1.0 版不寫入任務歷史項目。

## 權限

`activeTab` 與 `scripting` 只在使用者操作後讀取目前頁面；精確網站的持續權限為
選用且可撤銷。`storage` 保存本地偏好與選用快取，`sidePanel` 顯示介面，
`contextMenus` 提供選取文字操作，Ollama host 權限只限
`http://127.0.0.1:11434/*`。安裝時不要求所有網站的存取權。

## 分享、廣告與人員存取

發布者不會接收、出售、出租或分享擴充功能的使用者資料，也不會用於廣告、信用評估、
使用者側寫或無關用途。發布者與其他人員無法閱讀只在本地處理的頁面內容。

對 Chrome API 資訊的使用將遵守 Chrome Web Store 使用者資料政策及其 Limited Use
要求。

## 安全、變更與聯絡

真閱限制網路目的地、將可執行程式碼打包在擴充功能內、把頁面內容與模型輸出視為
不可信文字，並提供離線鎖定。若資料處理方式改變，政策與產品內揭露會先更新。
