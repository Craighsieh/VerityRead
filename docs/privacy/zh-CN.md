# 真阅隐私政策

生效日期：2026 年 7 月 26 日
发布者：VerityRead
联系邮箱：[craighsieh@gmail.com](mailto:craighsieh@gmail.com)

[English](./) · [繁體中文](../zh-TW/) · [日本語](../ja/) · [한국어](../ko/)

## 摘要

真阅是一款 Chrome 扩展程序，可摘要当前页面、根据页面原文回答问题并翻译所选文字。
内容只会通过 Chrome Built-in AI 在设备上处理，或发送到用户自己的本地 Ollama
服务 `http://127.0.0.1:11434`。

真阅不会将页面内容、所选文字、提示词、AI 回答、页面标题或网址发送给发布者、
云端推理服务、分析服务、广告商或数据经纪商。

## 访问与用途

只有在用户主动选择功能后，真阅才会临时访问当前页面的可读文字、标题、网址与域名、
用户选择的文字、输入的问题，以及在本地产生的摘要、翻译、回答与来源引用。这些数据
只用于提供用户请求的阅读功能。真阅不会持续扫描页面，也不会在后台收集浏览记录。

## 本地处理与网络

- Chrome Built-in AI、Translator 与 Language Detector 在 Chrome 设备端处理。
- Ollama 内容只发送到同一设备的 `127.0.0.1:11434`。
- 0.1.0 版没有云端推理 fallback。
- Chrome 可能下载模型或语言包，Chrome Web Store 可能更新扩展程序；真阅不会把
  页面内容加入这些由浏览器管理的请求。

## 存储与保留

默认不保存页面内容、所选文字、提示词、AI 回答或任务历史。真阅会在本地保存
Provider、模型、翻译目标、隐私同意版本和网站权限等偏好。

摘要缓存默认关闭。用户明确开启后，摘要及其页面网址可能保存在本地 IndexedDB，
直到用户清除缓存、清除所有本地数据或卸载扩展程序。0.1.0 版不写入任务历史条目。

## 权限

`activeTab` 和 `scripting` 只在用户操作后读取当前页面；精确网站的持续权限为可选且
可撤销。`storage` 保存本地偏好与可选缓存，`sidePanel` 显示界面，
`contextMenus` 提供所选文字操作，Ollama host 权限仅限
`http://127.0.0.1:11434/*`。安装时不要求所有网站的访问权限。

## 分享、广告与人员访问

发布者不会接收、出售、出租或分享扩展程序的用户数据，也不会将其用于广告、信用评估、
用户画像或无关用途。发布者和其他人员无法读取仅在本地处理的页面内容。

对 Chrome API 信息的使用将遵守 Chrome Web Store 用户数据政策及其 Limited Use
要求。

## 安全、变更与联系

真阅限制网络目的地，将可执行代码打包在扩展程序内，把页面内容与模型输出视为不可信
文字，并提供离线锁定。若数据处理方式发生变化，政策与产品内披露会先更新。
