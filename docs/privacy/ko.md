# VerityRead 개인정보 처리방침

시행일: 2026년 7월 26일
게시자: VerityRead
문의: [craighsieh@gmail.com](mailto:craighsieh@gmail.com)

[English](./) · [繁體中文](../zh-TW/) · [简体中文](../zh-CN/) · [日本語](../ja/)

## 요약

VerityRead는 현재 페이지 요약, 페이지 원문에 근거한 질문 답변, 선택한 텍스트 번역을
제공하는 Chrome 확장 프로그램입니다. 내용은 Chrome Built-in AI를 통해 기기에서
처리되거나 사용자가 직접 운영하는 로컬 Ollama
`http://127.0.0.1:11434`로만 전송됩니다.

페이지 내용, 선택한 텍스트, 프롬프트, AI 답변, 페이지 제목 또는 URL을 게시자,
클라우드 추론 서비스, 분석 업체, 광고 업체 또는 데이터 중개 업체로 보내지 않습니다.

## 접근하는 데이터와 이용 목적

사용자가 기능을 선택한 후에만 현재 페이지의 읽을 수 있는 텍스트, 제목, URL, 도메인,
선택한 텍스트, 입력한 질문 및 기기에서 생성된 요약·번역·답변·출처를 일시적으로
처리합니다. 이 데이터는 사용자가 요청한 읽기 기능을 제공하는 데만 사용됩니다. 백그라운드
에서 페이지를 계속 읽거나 방문 기록을 수집하지 않습니다.

## 로컬 처리와 네트워크

- Chrome Built-in AI, Translator 및 Language Detector는 Chrome 기기에서 처리합니다.
- Ollama 내용은 같은 기기의 `127.0.0.1:11434`로만 전송됩니다.
- 버전 0.1.0에는 클라우드 추론 fallback이 없습니다.
- Chrome이 모델·언어 팩 또는 확장 프로그램을 업데이트할 수 있지만, VerityRead는 이러한
  브라우저 관리 요청에 페이지 내용을 포함하지 않습니다.

## 저장 및 보관

기본적으로 페이지 내용, 선택한 텍스트, 프롬프트, AI 답변 또는 작업 기록을 저장하지
않습니다. Provider, 모델, 번역 대상, 개인정보 동의 버전 및 사이트 권한 등의 설정은
기기에 저장됩니다.

요약 캐시는 기본적으로 꺼져 있습니다. 사용자가 명시적으로 켜면 요약과 페이지 URL이
캐시 삭제, 전체 데이터 삭제 또는 확장 프로그램 제거 시점까지 IndexedDB에 저장될 수
있습니다. 0.1.0은 작업 기록 항목을 저장하지 않습니다.

## 권한

`activeTab`과 `scripting`은 사용자 작업 이후 현재 페이지를 읽는 데만 사용됩니다.
사이트별 지속 접근은 선택 사항이며 취소할 수 있습니다. `storage`, `sidePanel`,
`contextMenus`는 각각 로컬 설정, 화면 표시, 선택한 텍스트 작업에 사용됩니다. Ollama
호스트 권한은 `http://127.0.0.1:11434/*`로 제한됩니다. 설치 시 모든 웹사이트에 대한
접근 권한을 요구하지 않습니다.

## 공유, 광고 및 사람의 접근

게시자는 확장 프로그램 사용자 데이터를 수신, 판매, 대여 또는 공유하지 않으며, 광고,
신용 판단, 프로파일링 또는 그 밖의 관련 없는 목적으로도 사용하지 않습니다. 게시자나
다른 사람은 기기에서 로컬로 처리된 페이지 내용을 확인할 수 없습니다.

Chrome API에서 받은 정보의 사용은 Limited Use 요구사항을 포함한 Chrome Web Store
사용자 데이터 정책을 준수합니다.

## 보안, 변경 및 문의

VerityRead는 네트워크 대상을 제한하고 실행 코드를 확장 프로그램에 포함하며 페이지
내용과 모델 출력을 신뢰할 수 없는 텍스트로 취급하고 오프라인 잠금을 제공합니다.
데이터 처리 방식이 변경되면 적용 전에 정책과 제품 내 고지를 업데이트합니다. 문의 또는
개인정보 요청은 [craighsieh@gmail.com](mailto:craighsieh@gmail.com)으로 보내 주세요.
