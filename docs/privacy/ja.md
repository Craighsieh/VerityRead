# VerityRead プライバシーポリシー

施行日：2026年7月26日
公開者：VerityRead
連絡先：[craighsieh@gmail.com](mailto:craighsieh@gmail.com)

[English](./) · [繁體中文](../zh-TW/) · [简体中文](../zh-CN/) · [한국어](../ko/)

## 概要

VerityRead は、現在のページの要約、ページ内の根拠に基づく質問への回答、選択した
テキストの翻訳を行う Chrome 拡張機能です。内容は Chrome Built-in AI を使って
端末上で処理されるか、ユーザー自身のローカル Ollama
`http://127.0.0.1:11434` にのみ送られます。

ページ内容、選択テキスト、プロンプト、AI回答、ページタイトル、URLを、公開者、
クラウド推論サービス、分析事業者、広告事業者、データ仲介業者へ送信しません。

## アクセスするデータと利用目的

ユーザーが機能を選択した後に限り、現在のページの読み取り可能なテキスト、見出し、
タイトル、URL、ドメイン、選択テキスト、入力した質問、端末内で生成した要約・翻訳・
回答・出典を一時的に処理します。これはユーザーが要求した読書機能の提供にのみ使われ
ます。バックグラウンドでページを継続的に読み取ったり、閲覧履歴を収集したりしません。

## ローカル処理とネットワーク

- Chrome Built-in AI、Translator、Language Detector は Chrome の端末内で動作します。
- Ollama への内容送信は同じ端末の `127.0.0.1:11434` に限られます。
- バージョン 0.1.0 にクラウド推論へのフォールバックはありません。
- Chrome によるモデル／言語パックのダウンロードや拡張機能更新に、VerityRead が
  ページ内容を追加することはありません。

## 保存と保持期間

既定では、ページ内容、選択テキスト、プロンプト、AI回答、タスク履歴を保存しません。
Provider、モデル、翻訳先、同意したポリシーの版、サイト権限などの設定は端末内に
保存されます。

要約キャッシュは既定で無効です。ユーザーが明示的に有効にした場合、要約とページURL
は、キャッシュまたは全データの消去、もしくはアンインストールまで IndexedDB に保存
されることがあります。0.1.0 はタスク履歴を記録しません。

## 権限

`activeTab` と `scripting` はユーザー操作後の現在ページにのみ使用します。サイト単位
の継続アクセスは任意で、後から取り消せます。`storage`、`sidePanel`、
`contextMenus` はそれぞれローカル設定、画面表示、選択テキスト操作に使います。
Ollama の host 権限は `http://127.0.0.1:11434/*` に限定されます。インストール時に
すべてのサイトへのアクセスを要求しません。

## 共有、広告、人による閲覧

公開者は拡張機能のユーザーデータを受信、販売、貸与、共有せず、広告、信用判断、
プロファイリング、その他の目的に使用しません。ローカル処理されたページ内容を公開者
や第三者が読むことはできません。

Chrome API から受け取る情報の利用は、Limited Use 要件を含む Chrome Web Store
ユーザーデータポリシーに従います。

## セキュリティ、変更、連絡先

VerityRead は通信先を制限し、実行コードを拡張機能に同梱し、ページ内容とモデル出力を
信頼できないテキストとして扱い、オフラインロックを提供します。データ取扱いが変わる
場合は、事前に本ポリシーと製品内表示を更新します。お問い合わせは
[craighsieh@gmail.com](mailto:craighsieh@gmail.com) までお願いします。
